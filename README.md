# Pokédex

Pokédex is an interactive web application for exploring and searching various Pokémon, based on https://pokeapi.co.

This is a **practice project created as part of the Developer Akademie** program to deepen foundational web technologies in a practical, real-world scenario.

---

### Key Features

* **Pokémon Overview:** Displays Pokémon cards with name, image, and types.
* **Detail View:** Shows additional information such as general information or stats about the Pokémon.
* **API Logic:** All information is retrieved by https://pokeapi.co.
* **Search:** Quickly find specific Pokémon by name.
* **Responsive Design:** Optimized layout for both desktop and mobile devices.

---

### Installation

Follow these steps to run the project locally on your machine:

**01** Clone the repository
    ```bash
    git clone https://github.com/LeonHorter/Pokedex.git
    ```


**02** Navigate into the project directory
    ```bash
    cd Pokedex
    ```


**03** Open the project
    * Since this project uses pure HTML, CSS, and JavaScript, you don't need to install any dependencies.
    * Simply open the `index.html` file in your browser, or use an extension like **Live Server** in VS Code for the best experience.

---

### Technologies

* **HTML5** for structuring the content
* **CSS3** for responsive design and styling
* **JavaScript (ES6+)** for interactivity and data handling (e.g., via PokéAPI)
